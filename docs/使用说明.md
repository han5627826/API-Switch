# API Switch 使用说明

## 一、这是什么

一个本地桌面小工具，给以下 AI 编程工具**一键配置、切换自定义模型供应商（中转站 / 自建 API）**：

| 页签 | 目标软件 | 作用 |
|------|----------|------|
| Codex | ChatGPT 桌面版 / Codex CLI | 添加/切换 API 供应商（写入 `~/.codex/config.toml`） |
| Qoder | Qoder 桌面版 | 一键导入自定义模型（写入 `~/.qoder/settings.json`，新版 BYOK 格式） |
| Qoder CN | Qoder CLI / Qoder CN | 写入 `~/.qoder-cn/settings.json` 的 BYOK 配置 |
| ZCode | ZCode | 导入并一键启用切换（写入 `~/.zcode/v2/config.json`） |
| TRAE Work CN | TRAE SOLO CN | 辅助导入 + 查看/停用/删除已有自定义模型 |
| 目标管理 | —— | 各软件的检测状态与导入用法一览，引导首次使用 |


**工作原理**：程序启动后在本机 `127.0.0.1:8765` 开一个仅本机可访问的 Web 服务，界面（原生 WebView2 窗口）通过它读写各家软件的配置文件。API Key 保存时用 Windows DPAPI 加密，只在本机可解密，不会明文散落。

## 二、核心概念：供应商库

- 所有供应商统一保存在 `%APPDATA%\APISwitch\providers.json`，四个页签共用这一份库。
- 库里自带一个不可删除的 **「原始配置（original）」**：代表 ChatGPT 官方账号登录，用于随时还原。
- 在 Codex 页签添加好供应商后，Qoder / Trae / Qoder CN 页签的下拉框里就能直接选它，**一次录入，处处使用**。

## 三、Codex 页签（主功能）

### 3.1 添加供应商

点右上角 **「＋ 添加供应商」**，填写：

1. **名称**：自定义一个易识别的名字，如 `My Relay`。
2. **API 格式**：
   - `Responses（原生 /responses）`：站点支持 OpenAI Responses 接口时选它（Codex 原生方式，推荐）；
   - `Chat Completions（/v1/chat/completions）`：普通 OpenAI 兼容中转站选它。
3. **Base URL**：填你的站点地址，例如 `https://api.your-provider.com/v1`。带不带 `/v1` 取决于站点路由，保存前用「测试连接」验证。
4. **鉴权方式**：
   - `auth.json（推荐）`：Key 写入 `~/.codex/auth.json`；
   - `环境变量`：Key 通过 `setx` 写入用户环境变量（环境变量名留空会按名称自动生成，如 `MYRELAY_API_KEY`）。
5. **API Key**：粘贴站点给的 Key（👁 按钮可切换明文查看）。
6. **推理力度**：`low / medium / high / xhigh`，留空则跟随模型默认。
7. **模型列表**：
   - 点 **「⟳ 获取模型列表」** 自动从站点拉取，点击模型芯片可选中/取消，✕ 删除；
   - 拉不到时在输入框**手动输入模型 ID 后回车**添加；
   - 选好后设置 **默认模型** 与 **Review 模型**。
8. **上下文 / 最大输出**：选定模型后会自动识别其上限（内置 models.dev 规格表 + 启动时在线更新）。手动改过数字后自动识别暂停，切换模型可重新触发。
9. 点 **「测试连接」** 发一条真实请求验证（显示耗时和模型回复），通过后 **「保存」**。

保存成功后，右侧详情里点 **「启用此配置」** 即完成切换。工具会在 `config.toml` 里写一段「managed block」托管区块（含 `model_provider`、`model_catalog_json` 等），不会破坏你原有的 MCP、插件等设置；首次切换前自动备份为 `config.original.toml`、`auth.original.json`。

### 3.2 切换与还原

- **切换**：点供应商卡片 → 「启用此配置」→ 提示「重启 Codex 后生效」。
- **重启 Codex**：工具栏「重启 Codex」按钮结束正在运行的 ChatGPT.exe / codex.exe 并以当前配置重启（运行中先弹确认框）。
- **还原官方**：选列表顶部的「原始配置」→ 启用此配置。

### 3.3 网络设置

右上角 **「网络设置」** 可填本地代理。

- 仅影响本工具内的 **「测试连接」** 和 **「获取模型列表」**；
- 内部走系统 `curl.exe`，可绕开某些 Python 请求被 Cloudflare 拦截的问题；
- **不影响 Codex / Qoder 等本身的联网**。留空 = 直连。

## 四、Qoder 页签（桌面版 · 新版格式）

1. 左侧选供应商 → 勾选模型（自动识别上下文 / 输出 / 视觉 / 推理）→ 点 **「一键导入到 Qoder」**。
2. 右侧可查看、删除 `~/.qoder/settings.json` 中现有的自定义供应商。
3. Qoder 正在运行也能导入（新配置在下次启动生效）；同名 Base URL 会合并进同一条目。

说明：新版 Qoder 的自定义模型直接保存在 `settings.json` 的 `providers` 中（`apiKey` 为明文，与 Qoder 自身行为一致），不再依赖旧版云端 BYOK 白名单。旧版「云端状态诊断」提示的 `enabled=false` 限制不影响此格式。

## 五、ZCode 页签

1. 左侧选供应商 → 勾选模型 → 点 **「一键导入到 ZCode」**，写入 `~/.zcode/v2/config.json` 的 `provider`（与 ZCode 手动添加的自定义供应商格式一致）。
2. 右侧列表显示 ZCode 现有自定义供应商，点 **「启用」** 即一键切换（互斥：启用一个自动停用其它）；可删除本工具导入的条目。
3. 改动后需**重启 ZCode** 生效。ZCode 的 API Key 为明文保存，与 ZCode 自身一致。

## 六、TRAE Work CN 页签（辅助导入 + 模型管理）

TRAE 对自定义模型 Key 使用闭源私有加密，外部工具无法代写密文，因此采用「信息预填」导入：选择供应商 → 点 **「复制模型信息并启动 TRAE」** → 在 TRAE「设置 → 模型管理 → 添加模型」中选 **OpenAI 兼容** 粘贴即可。

同时本页签支持**管理**：右侧列出 TRAE 现有自定义模型（从 `state.vscdb` 读取），可「停用 / 启用」或「删除」（操作前需完全退出 TRAE，改动前自动备份数据库）。

## 七、目标管理页签

首次使用建议先看这里：每个受支持软件的检测状态（已检测到 / 运行中 / 未检测到）、写入位置与导入步骤一目了然，点「前往导入」直接跳到对应页签。添加完供应商后，保存提示也会引导你去各页签导入。

## 八、Qoder CN 页签

面向 Qoder CLI / Qoder CN：选择供应商 → 勾选模型 → 点 **「一键导入到 Qoder CN」**，写入 `~/.qoder-cn/settings.json` 的 `providers`，格式与原生 BYOK 一致；下次对话时生效。右侧可查看、删除。

## 九、一键更新

- 工具启动约 1.5 秒后自动向 GitHub 查询最新版本，**不打扰你**；发现新版才在右上角显示「发现新版本 vX.Y.Z」按钮。
- 点击按钮 → 确认 → 自动下载新版本（右上角实时显示进度），下载完成后自动进行 **SHA-256 完整性校验**；
- 校验通过后点「立即重启安装」：程序自动关闭，用新版本覆盖旧文件并重新启动，供应商配置全部保留，全程约 10 秒；
- 任何一步失败（断网、校验不过）都不会破坏现有程序，会提示原因并可重试；
- 无网络 / GitHub API 限流时检查静默跳过，不影响任何功能。

## 十、常见问题

**Q1：切换了配置但 Codex 还是旧模型？** 正在运行的 Codex 需重启，用「重启 Codex」按钮或手动重启。

**Q2：「获取模型列表」失败？** ① 检查 Base URL（带不带 `/v1` 换个写法）；② 不可直连时在「网络设置」填代理；③ 部分站点不开放 `/models`，改用手动输入模型 ID。

**Q3：「测试连接」报错？** 401/403 = Key 不对或 API 格式选错（Responses vs Chat 换一种）；404 = Base URL 或路径不对；超时 = 走代理试试。

**Q4：Qoder 导入按钮灰的？** 未安装 Qoder 或 Qoder 正在运行（含托盘）。

**Q5：想换电脑 / 备份？** 拷贝 `%APPDATA%\APISwitch\providers.json` 可迁移供应商列表，但 DPAPI 密文与本机绑定，新电脑需重新粘贴各站点 Key。

**Q6：SmartScreen 提示「已保护你的电脑」？** 这是未签名 exe 的正常提示，点「更多信息 → 仍要发布」。介意者可在防火墙里断网测试后再放行。

## 十一、卸载

直接删除 exe 即可；如需清除数据，删除 `%APPDATA%\APISwitch` 文件夹。已写入 Codex / Qoder 等配置文件的内容不会自动回滚，如需还原：用本工具选「原始配置」启用，或用各自的 `*.original.*` 备份文件恢复。
